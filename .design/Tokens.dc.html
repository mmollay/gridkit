Blatt 03 Die vorgeschlagene Token-Schicht

Weniger Werte, mehr Regeln

Ein Design-System wird nicht dadurch edel, dass es mehr Werte hat, sondern dadurch, dass jede Entscheidung nur einmal getroffen wird. Vier Schichten fehlen GridKit heute vollständig: eine Farbregel, eine Typo-Skala, eine Bewegungs-Handschrift und eine Höhenordnung.

01

Farbe — ein Theme ist ein Winkel

Die sechs Themes sind heute von Hand aus einer Tailwind-Palette gepflückt. In OKLCH gemessen streut ihre Helligkeit von 0,45 bis 0,69 und ihre Buntheit von 0,04 bis 0,21 — deshalb wirkt Amber viel leichter als Slate und Rose lauter als Forest. Es ist kein Satz, sondern eine Sammlung.

Der Vorschlag hält Helligkeit fest und variiert nur den Farbwinkel. Die Buntheit läuft dabei gegen die sRGB-Grenze — Cyan und Grün können bei dieser Helligkeit nicht so bunt werden wie Indigo. Genau das erledigt oklch() im Browser von selbst, wenn man den Wunschwert notiert.

--gk-hue: 277; /* das ganze Theme */ --gk-primary: oklch(0.60 0.15 var(--gk-hue)); --gk-primary-container: oklch(0.95 0.04 var(--gk-hue)); --gk-on-primary-container: oklch(0.36 0.11 var(--gk-hue));

Ein siebtes Theme kostet danach eine Zeile statt zwanzig — und kann nicht mehr aus der Reihe fallen.

02

Typografie — sieben Rollen statt sechzehn Zahlen

Token Größe / Höhe Musterzeile Einsatz
--gk-text-display 32 / 1,15 / 600 Rechnungen Seitentitel, genau einer je Ansicht
--gk-text-title 20 / 1,30 / 600 Offene Posten Abschnitt innerhalb der Seite
--gk-text-subtitle 16 / 1,40 / 600 Zahlungsziel überschritten Kartenkopf, Modal-Titel
--gk-text-body 14 / 1,55 / 400 Der Betrag wird am 30. fällig. Fließtext, Tabellenzellen — die Grundgröße
--gk-text-label 13 / 1,40 / 500 Rechnungsempfänger Formularbeschriftung, Schaltflächen
--gk-text-caption 12 / 1,45 / 400 Zuletzt geändert vor 3 Tagen Hilfstext, Zweitzeile in der Zelle
--gk-text-overline 11 / 1,30 / 600 Artikel-Nr. Tabellenkopf, Abschnittsmarke — nur hier

Jede Rolle bringt Größe, Zeilenhöhe und Gewicht mit. Das ist der eigentliche Gewinn: Heute steht an 38 Stellen font-size: 14px ohne zugehörige Zeilenhöhe — die entsteht dann zufällig aus dem Kontext.

03

Bewegung

--gk-dur-1120ms
Zustand am Ort: Hover, Fokus, Auswahl
--gk-dur-2200ms
Erscheinen und Verschwinden: Dropdown, Tooltip, Toast
--gk-dur-3320ms
Bewegung im Raum: Modal, Schublade, Seitenleiste
--gk-ease-out cubic-bezier(0.2, 0, 0, 1) Alles, was hereinkommt. Schnell ansetzen, weich ankommen.
Und: transition: all verschwindet. Es animiert auch Breite, Höhe und Position — die häufigste Ursache für Layouts, die beim Aufklappen zucken.
04

Höhe & Fokus

e0 flach
e1 Karte
e2 Dropdown
e3 Modal

Jede Stufe ist zweilagig: ein enger Kontaktschatten für die Kante, eine weiche Streuung für die Distanz. Ein einlagiger Schatten sieht immer aufgeklebt aus. Im Dark Mode übernimmt eine hellere Fläche die Rolle des Schattens — Schwarz auf Schwarz trägt nicht.

--gk-focus-ring Ein Ring, überall gleich, nur bei :focus-visible.
